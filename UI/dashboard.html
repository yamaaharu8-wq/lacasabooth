Google Drive ☁️

Atur pengiriman file hasil foto dan video langsung ke cloud storage pelanggan Anda.

📡 Mode Penyimpanan Utama

Penjelasan Mode:

  • ONLINE: Hasil foto (GIF/Video/Collage) dikirim ke G-Drive, dapat QR Code (Butuh internet).
  • OFFLINE: Data hanya disimpan di laptop. QR Code mati. Mempercepat proses cetak.
🔑 Koneksi Akun Google Drive

Cara Tepat Menghubungkan Folder G-Drive:

  1. Klik tombol 🔑 Login G-Drive, izinkan akses.
  2. Buka situs G-Drive, buat folder (Misal: "Photobooth Sesi").
  3. Share folder menjadi "Siapa saja memiliki link".
  4. Buka folder, ambil ID Folder dari URL browser. (Kodenya saja!)
  5. Tempel di form bawah, klik Simpan.
